Memory Data Format

The maximum size of each memory location is 16 bits. The first 4 leading bits correspond to the instruction (or opcode). The remaining 12 bits correspond to the operand. Operands as immediate values use 12-bit two's complement integers.

super simple cpu

A CPU simulator designed to visualize the Von Neumann architecture.

1 Write or Load

Write code in the Assembly Window, select an Example, or edit RAM cells directly.

2 Assemble

If you wrote custom code in the Assembly Window, click Assemble to Binary to compile it into RAM.

3 Execute

Click Auto Run or Next Step. The app will switch views automatically to show the execution cycle.
